Hunter & Hunter — asset network, mobile v2

Marked, readable, filterable

Three changes on top of the last version: the manager's own mark identifies every tier and every row group, addresses get their own line instead of an ellipsis, and the buildings screen filters down without leaving the screen.

Marks

Both managers publish a dark-inked wordmark, so on the terminal ground each sits on a light plate rather than being recoloured — a partner's mark is not ours to alter. The mark appears on the vehicle node in the graph, at the head of each fund's figures, on the fund filter chips, and as a sticky header in the asset list so you always know whose building you are looking at while scrolling.

Addresses

The row is two lines now. The address gets the full width on line one; market, type and suite count drop to a dimmer line beneath. Nothing is truncated — the longest name in the portfolio, Unit 15, 495 WT Hill Boulevard S, fits with room to spare. It costs about 14px of height per row and removes every ellipsis.

Filters

A chip row that scrolls sideways, so it never wraps and never steals height from the list. Filter by manager or by province; the count above the list stays honest about what you are seeing and what you are not. With two funds and three provinces it is five chips today, and it grows sideways rather than downward as offerings are added.

Nothing committed. Preview only — no application code has changed and nothing is pushed.
